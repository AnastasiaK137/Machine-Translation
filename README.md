# Mashine-Translation
Лабораторная работа №1
**Студент:** Конухова Анастасия Александровна
**Группа:** ИНФА-221
**Вариант:** 8 (Атомная энергетика и реакторные технологии)
**Цель работы:** научиться программно обрабатывать стандарты обмена терминологическими данными, реализовать поиск нечётких совпадений (**Fuzzy Match**) и подстановку терминов глоссария, а также экспортировать результат в CAT-систему Smartcat.

В ходе работы необходимо были решены **следующие задачи**:

1. Разобрать и валидировать XML-схему терминологической базы TBX.
2. Извлечь параллельные сегменты из памяти переводов TMX.
3. Реализовать метрику сходства строк и поиск нечётких совпадений с ранжированием.
4. Реализовать автоматическую подстановку терминов глоссария в исходный текст.
5. Экспортировать результаты в формате, пригодном для импорта в Smartcat.

Исходные данные:
- **Глоссарий TBX:** 100 терминов EN–RU по атомной энергетике (`variant_8.tbx`).
- **Память переводов TMX:** 100 параллельных предложений EN–RU (`variant_8.tmx`).
- **Домен:** Nuclear Energy / Atomic Industry.

Термины проверялись по глоссариям МАГАТЭ (IAEA Safeguards Glossary, IAEA Safety Glossary) и учебным материалам по ядерной физике.
